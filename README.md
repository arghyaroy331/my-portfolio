# Arghya Roy — Personal Portfolio

A minimalist, clean personal developer portfolio for **Arghya Roy** (Cloud & DevOps Enthusiast | Software Developer), visually inspired by the clean, minimal aesthetic, typography, and card interactions of [subinoy.me](https://www.subinoy.me/).

---

## 🚀 Key Highlights & Design Language

- **Visual Inspiration**: Clean, elegant typography hierarchy, comfortable whitespace, subtle 0.5-degree card tilts that straighten on hover (`rotate-[0.5deg]` / `-rotate-[0.5deg] hover:rotate-0`).
- **Dark & Light Mode Support**: Seamless theme switching with exact OKLCH color palettes, backdrop-filter glass navbar, and theme persistence in `localStorage`.
- **Vertical Timeline**: "Education & Technical Experience" timeline with dashed vertical track, circular badges, and interactive `<details>` accordion summaries.
- **Project Cards**: 2-column responsive grid displaying verified cloud and software projects with technology pills and external links.
- **Skills & Technologies**: Categorized minimal skill tags (Cloud Computing, DevOps, Programming, Web Development, Core Computer Science).
- **Achievements & Highlights**: Clean highlight cards for team leadership, infrastructure automation, AWS monitoring, and multi-tier architectures.
- **Minimalist Contact & Footer**: One-click copy email button, social links (GitHub, LinkedIn), and clean footer.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS with OKLCH theme variables
- **Typography**: Lato, Fira Code, Grand Hotel
- **Language**: TypeScript

---

## 📦 Getting Started

```bash
# Navigate to directory
cd c:\Portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
